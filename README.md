# SET MCQ Generator

Automated Question Bank generator for State Eligibility Test (SET) Political Science using Gemini 2.5 Flash and GitHub Actions.

## Setup Instructions

1. Upload your study notes or PYQ PDFs to the `inputs/` folder.
2. Set your Gemini API key in GitHub Repository Settings -> Secrets and variables -> Actions as `GEMINI_API_KEY`.
3. Go to the **Actions** tab -> **Generate SET Question Bank CSV** -> **Run workflow**.
